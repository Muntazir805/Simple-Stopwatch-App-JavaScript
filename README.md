# ⏱️ Simple Stopwatch App

A simple and responsive **Stopwatch App** built using **HTML, CSS, and JavaScript**.

This project was created as a practice project to improve JavaScript concepts such as **DOM manipulation, events, timers, functions, arrays, and dynamic content rendering**.

## 🚀 Features

* ▶️ Start the stopwatch
* ⏹️ Stop the stopwatch
* 🔄 Reset the stopwatch
* 🔖 Save the current stopwatch time
* 📋 Display saved times
* 🔢 Store up to 5 saved times
* 📱 Responsive design
* 🌙 Dark premium UI
* 🟢 Green neon stopwatch design
* 🔤 Font Awesome icons for controls

## ⚙️ How It Works

### Start

Click the **Play** button to start the stopwatch.

### Stop

Click the **Stop** button to pause the stopwatch.

### Save

Click the **Bookmark** button to save the current stopwatch time.

The saved time remains unchanged even when the stopwatch continues running.

### Reset

Click the **Reset** button to:

* Reset the timer to `00:00:00`
* Stop the timer
* Remove all saved times
* Reset the saved counter
